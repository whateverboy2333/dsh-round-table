## 新增契约 / New contracts

### 当前自由步骤合同 / Current free-step contract

自由步骤以`steps.version=1`及workflow schema3保存；schema1/2历史保留、未知4+只读。空/未完整steps草稿可以validate/save，但layout与运行预览使用严格图校验；运行时每项必须有效名称且恰一名普通成员。初始preview/start面向第一阶段全部真实nodeIds，包含首阶段并行；`confirmed:true`启动首阶段并授权预览里明确勾选的未来规则，未勾选未来环节仍需手动开始。新逐环节UI没有全局手动/自动下拉。内部entry/join helper只计算依赖，不可activate、暂存输入、持有秘书job或消耗配额。 / Schema3 stores the free-step layout; old schema1/2 remains intact and future versions are read-only. Partial drafts may validate/save, but layout and execution are strict. Initial preview/start authorizes every real first-stage item and selected future automatic rules; unchecked future steps remain manual. Internal helpers have no execution authority.

Agent工具调用要求exec.agent为当前真实实例及未归档原会话。meeting_list与meeting_minutes_data限定本人参加／可信创建／专属秘书的会议；meeting_join只允许可信创建者邀请或成员幂等确认自己已在会，禁止非成员自行加入陌生会取得文件读取权。可信创建者绑定原会话身份，同SID替代不继承。宿主管理HTTP保持用户管理入口。 / Agent tools require an authentic current, unarchived session. Lists and minutes are scoped to owned or joined meetings, and joining cannot self-grant access to an unfamiliar meeting. Creator authority is bound to the original session incarnation; host user management remains available.

`GET /plugins/round-table/local-scope` 为桌面用户面的只读实例识别接口，返回 home/profile 的稳定不透明哈希 `scope` 及 `profileName`；缺少宿主身份返回503。草稿、待核实请求及视图按该标识隔离，识别前不读取旧草稿。旧未分区记录只能在用户核对归属后导入，原记录保留。 / This read-only identity endpoint returns a stable opaque home/profile scope and profile name, or 503 when the host identity is absent. 会议操作可携带 `x-round-table-scope`；与当前实例不符时返回409且 `requestState: rejected`，不执行操作。它用于阻止旧实例草稿投向新实例，不替代宿主访问控制。 / A mismatched scope header rejects the operation before execution; it is a stale-instance guard, not an authentication mechanism.

`POST /plugins/round-table/meetings` 新增可选 `requestId`（1–100位字母、数字、下划线或连字符）。同ID和同初始标题、说明、工作区、成员返回同一会议；改内容的重试拒绝。客户端保存此请求身份再创建，成员续建独立记录阶段。 / An optional creation request ID recovers the same meeting after a lost response; reusing it for different initial content is rejected.

```ts
interface ChatInput {
  kind?: 'message' | 'task'
  contextTaskId?: string
  mode: 'record' | 'send' | 'queue'
  instruction: string
  messageIds: string[]
  assetIds: string[]
  recipientIds: string[]
  runId: string | null
  nodeId?: string
}
```

`record`只记录。新客户端显式传 `kind:"message"`，`send`冻结明确正文及资料、建立普通 discussion 投递，不创建 ReleaseDraft／工作任务／流程激活或消耗任务次数额度；忙碌原窗口通过 FIFO 接收。`contextTaskId` 必须属于本会，只关联澄清，不改任务要求或状态。显式 `kind:"task"` 的 `send` 保留任务放行语义；省略 kind 兼容旧客户端的任务发送，因此新客户端不能靠省略来发送普通消息。`queue` 暂存到已有流程目标，不接受 `kind:"message"`。`requestId` 是同次重试身份（1–70位字母、数字、下划线或连字符），同 ID 不能换内容；fingerprint 变更需新预览。 / `record` only saves. New clients explicitly use `kind:"message"`: `send` freezes selected text/materials into a discussion delivery without a release draft, work task, workflow activation or task-attempt charge; busy original sessions receive it through FIFO. `contextTaskId` must belong to this meeting and only links clarification without changing task requirements or state. Explicit `kind:"task"` retains work release semantics; omitted kind preserves legacy task sending, so new clients must not omit it for ordinary messages. `queue` stores input for an existing stage and rejects message kind. Retry IDs use 1–70 letters, digits, underscores or hyphens; keep the same ID/content for the same attempt. Changed fingerprints require another preview.

`revision-start`返回409并带 `requestState:"rejected"` 才明确表示本次预提交校验拒绝；保留意见、新预览。一般存储或网络失败不带这个标记时可能已提交，应核对并重试原requestId，不能盲建第二项修改。 / A 409 with `requestState:"rejected"` explicitly identifies pre-commit rejection; retain notes and preview again. Other storage/network failures may follow commit: verify and retry the same request ID instead of blindly creating another revision.

`publish-reply.taskId`支持delivered/in_progress/uncertain/failed的放行任务人工补交，不覆盖已完成结果。摘录校验和摘要验证由宿主源码执行，客户端不能替换正文。 / Manual fill-in supports delivered/in_progress/uncertain/failed release tasks and does not overwrite completed results. Host-side provenance checks prevent client-supplied replacement text.

## 归档准入与状态 / Archive admission and state

归档会议允许 `archive, pin, export, lookup-message, asset-read, asset-download, meeting-folder-status, meeting-file-read, minutes-data, member-status, member-reply, publish-candidates, list-templates`；永久删除单独进入删除准入门。其他动作要求先恢复。 / Archived meetings allow these reads and management actions; permanent deletion has separate admission. Other actions require restoration first.

放行任务状态为 `queued, offline, delivering, uncertain, delivered, in_progress, completed, failed, cancelled`；验收状态独立为 `accepted|changes_requested`。`delivered`不代表阅读或完成，`uncertain`不允许盲目重发。 / Release states are distinct from acceptance. Delivered is not read or complete; uncertain delivery must not be blindly resent.

同一DSH_HOME仅一个队列宿主；跨profile不隔离默认存储，不支持跨进程exactly-once。冻结输入不隔离原会话记忆和权限。 / One queue host per DSH_HOME; default storage is shared across profiles, without cross-process exactly-once. Frozen evidence does not isolate session memory or permissions.
