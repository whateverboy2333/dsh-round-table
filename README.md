# dsh-round-table · 圆桌骑士

**中文** | [English](README.en.md)

让多个 Agent 原窗口在同一场会议中讨论、协作和交付。普通问答直接发送；需要执行时，由所选成员生成任务卡，核对后发布。成员工作日志、共享资料、自由步骤和独立秘书纪要集中在会议内，成员保留原会话与上下文。

**当前源码1.0.0，尚未公开发布。** 本次仅调整版本编号，功能沿用已验收的0.1.18；以下安装使用已发行0.1.18。

## 安装

**宿主要求：Windows DeepSeek Harness 0.2.0-rc.2，目标 profile 为 desktop。** 在桌面「插件」页添加 `dsh-round-table@0.1.18`，然后从应用菜单或托盘**退出**并重新打开，点击侧栏「圆桌」。仅关闭窗口不等于完全退出。

也可使用桌面发行版自带的 CLI；先退出应用，不使用 PATH 中可能属于其他安装的裸 `dsh`：

```powershell
$desktopCli = Join-Path $env:LOCALAPPDATA 'Programs/DeepSeek Harness/resources/runtime/cli/bin/dsh.cmd'
& $desktopCli --version   # 应为 0.2.0-rc.2
& $desktopCli plugin --profile desktop add 'dsh-round-table@0.1.18'
```

## 五步开始

1. **建会并选人：** 填写目标、背景与工作区，邀请已有窗口或从宿主预设新建成员。创建会发送入会简报，成员可能回应；每会有独立秘书。
2. **先讨论：** 输入 `@` 并从菜单选成员，发送普通问题；没有选人时只记录到会议。图片、文档可拖入，截图可粘贴。Enter发送／记录，Ctrl／⌘+Enter换行。
3. **需要工作时生成卡：** 已@成员后点击「任务卡生成」，正文可为空。每个待办返回一张卡；生成和调整不执行卡内工作，不自动识别聊天意图来派任务。
4. **核对后发布：** 直接修改正文，或让原生成者按意见调整；保存、确认责任成员并选择卡片，再确认发布。批准版本先写本会目录，随后通知所选成员执行；提交结果与人工验收分开。
5. **持续跟进：** 在右侧成员日志查看回应和工作状态；固定协作可在进程页自行编排。秘书按需生成纪要草稿，核对后再选择公开、通知或导出。

## 界面与用法

以下为**0.1.18生产React界面**，使用合成会议、成员与材料，**不是实际Agent执行结果**；主窗口为布局示例。

### 讨论与并排工作

默认380px侧栏与原页面并排，可拖宽；关掉再打开恢复默认大小。正文与附件同条发送，上传仅归档。图片能否交给Agent读取仍取决于模型能力。

![圆桌讨论与主窗口并排布局示例](docs/assets/meeting-overview.png)

### 任务卡：生成、修改、选择发布

生成者与责任成员分别显示。原稿、手工修改和AI调整建议保留版本，晚到建议不覆盖用户编辑；只有核对选定版本并确认发布才通知执行。

![任务卡清单、全文编辑和选定发布](docs/assets/task-cards.png)

### 成员详情与会议工作日志

右侧边栏集中显示本会资料、投递、回应、正式成果及验收。执行需要时恢复同一原会话；归档、删除或身份无法确认时提示处理，不创建替代窗口。

![右侧成员详情与会议工作日志](docs/assets/member-log.png)

### 自由步骤：顺序、并行和删除

从空白开始，直接改标题，每行选择成员，同一Agent可负责多个环节。任意阶段可并行，标题栏常驻删除，自动运行默认关闭。保存只记录安排；首轮预览确认启动首阶段，并授权已勾选的后续规则，未勾选的后续步骤仍手动。活动结构及已开始字段冻结，旧图与历史保留。

### 资料与会议文件夹

本会成功上传的文档、图片及版本均归档，移除草稿引用不删原件。工作区中的专属会议文件夹保存材料、批准任务卡、成果和纪要，成员按批准版本读取。

![会议资料、版本与共享目录](docs/assets/materials.png)

### 秘书纪要

先生成草稿，再核对会议来源和任务事实。公开到会议只新增记录；发送通知才唤醒成员，也可以保留不发送。纪要不能自动证明全部内容正确。

## 使用边界

- 仅上述桌面版本；成员在同一DSH进程，同一DSH_HOME只运行一个圆桌队列宿主。不支持跨机器或定时纪要。
- 日志不自动公开其他私聊；成员保留原上下文及文件权限，会议资料选择不构成权限隔离。秘书不执行普通成员工作。
- 图片投递需模型适配器明确支持，当前DeepSeek适配器不支持；PDF、Office、RAR等可保存完整原件，不自动解析或解压。具体大小见[指南](docs/配置指南.md#资料与纪要)。
- 保存流程不启动工作；生成或调整任务卡会请求成员分析，确认发布才执行卡内工作，纪要生成也会使用模型。送达、提交与验收是不同状态；不确定投递先核对，重试可能重复。执行额度不是Token或费用硬上限。
- 升级前备份数据。永久删除会议需二次确认且无回收站；普通成员与工作文件保留，停止会议不终止原Agent。旧版本回退依赖完整备份。
